# Odoo Domain Skills Roadmap

This document tracks the planned and completed Gemini CLI Skills for the Brass-Monkey extension. Skills are categorized into two layers: Structural Mastery (Operating Odoo) and Functional Domains (Executing Business).

## 🛠️ Layer 1: Structural & Operational
*Focus: How the agent navigates and operates the Odoo engine safely.*

| Skill | Description | Status |
| :--- | :--- | :--- |
| `odoo-workspace` | Multi-instance management, Auth, and switching. | ✅ Done |
| `odoo-introspector` | ORM mastery, model/field inspection, and property logic. | ✅ Done |
| `odoo-ux` | Navigation flow: Menus ➔ Actions ➔ Views. | ✅ Done |
| `odoo-data-ops` | Domain syntax, CRUD logic, and Agent-Driven Undo. | ✅ Done |
| `odoo-reports` | Discovering and downloading QWeb/PDF documents. | ✅ Done |
| `odoo-knowledge` | Reading and writing Knowledge Articles. | ✅ Done |
| `odoo-documents` | Managing Attachments and Document workspaces. | ✅ Done |
| `odoo-dev` | Advanced technical tasks, Server Actions, and code analysis. | ✅ Done |
| `odoo-security` | Access Rights, Record Rules, and Multi-company. | ✅ Done |
